# Índice documental

Lee solamente los documentos relacionados con la tarea.

## Fuentes canónicas

- [PROJECT_STATE.md](PROJECT_STATE.md): estado vigente, despliegue y límites del sistema.
- [architecture.md](architecture.md): estructura, flujo de datos y contratos internos.

## Planes de tareas

`tasks/` contiene únicamente planes de trabajos largos activos o recientemente completados. No son fuentes del estado actual ni un historial permanente.

Formato obligatorio: `AAAA-MM-DD-HHMM-descripcion.md`.

## Historial

Git es la fuente del historial. No se mantienen bitácoras de sesiones ni reportes de cambios dentro de la documentación activa.
